🍽️ Spice Haven — Fine Dining & Authentic Flavours

A modern, premium restaurant website designed for Spice Haven, an Indian fine-dining restaurant focused on authentic flavours, elegant presentation, and memorable dining experiences.

🔗 Live Demo: https://spice-haven-fine-dining-authentic-flavours.ai.studio

📌 About the Project

Spice Haven is a responsive restaurant website created as a professional web-development demo.

The website is designed to give a restaurant a strong online presence and make it easier for customers to:

Discover the restaurant
Explore the menu
View popular dishes
Learn about the restaurant
Read customer reviews
Browse the gallery
Make a reservation
Find contact information

The design focuses on a premium dining experience while keeping the interface simple and easy to navigate.

🚀 Getting Started
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project
cd spice-haven
3. Install dependencies
npm install
4. Start the development server
npm run dev

The application will be available at the local development URL shown in your terminal.
